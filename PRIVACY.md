# Privacy Policy

AI Sloplation Filter is designed to work locally in your browser.

## Data Collection

AI Sloplation Filter does not collect, sell, share, transmit, or store personal information on any external server.

The extension does not collect:

- browsing history
- account credentials
- cookies
- manga reading activity
- page content
- analytics or usage events

## Local Storage

The extension uses browser local storage only to save your settings, including:

- whether filtering is enabled
- whether matching items are hidden or dimmed
- your blocked uploader list
- your always-allowed uploader list

This information stays in your browser unless you choose to export it.

## Site Access

AI Sloplation Filter runs only on `mangago.me` and `www.mangago.me`. It reads visible page text locally so it can hide or dim items that match your blocked uploader list.

## Remote Code

AI Sloplation Filter does not load or execute remote code.

## Contact

For support or privacy questions, use the GitHub repository issue tracker.
