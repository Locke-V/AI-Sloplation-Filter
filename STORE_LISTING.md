# Chrome Web Store Listing Copy

## Name

AI Sloplation Filter

## Short Description

Filter AI slop scanlation uploads on Mangago.

## Detailed Description

AI Sloplation Filter helps manga and manhwa readers keep noisy upload groups out of sight on Mangago.

Use a local blocklist to hide or dim chapter rows, update items, and visible in-site notification entries from uploaders you do not want to see. The starter blocklist includes Desire Scans, Myth Toons, Kaizen, Spring, Springtoons, and Desire. The always-allow list starts blank.

Features:

- Hide matching uploader groups
- Dim and label matches instead of hiding them`r`n- Optionally move unfiltered chapters above dimmed filtered rows
- Edit blocked and allowed uploaders from the popup
- Import and export your settings as plain JSON
- Runs only on Mangago pages
- No accounts, analytics, remote code, or external servers

Privacy:

AI Sloplation Filter stores your blocklist and settings locally in your browser. It does not collect personal data, send page content anywhere, read cookies, or track browsing history.

Important limitation:

This is a local page filter. It can hide matching chapters, updates, and visible in-site notification entries after Mangago sends them to your browser. It cannot change Mangago's server-side notification system.

## Category

Productivity

## Privacy Field Suggestions

Single purpose:

Filters visible Mangago page items from user-blocked uploader groups.

Storage permission:

Stores the user's local blocklist, allowlist, and display settings.

Host permission:

Runs only on Mangago pages to hide or dim visible items matching the user's local blocklist.

Remote code:

No. The extension does not load or execute remote code.

Data collection:

No user data is collected or transmitted.

## Reviewer Test Instructions

1. Install the extension.
2. Open the extension popup and confirm filtering is enabled.
3. Add a test uploader name to the blocked list.
4. Visit a Mangago page containing that visible uploader text, or use a local test page with chapter/update rows containing that uploader name.
5. Confirm matching rows are hidden or dimmed depending on the selected filter style.
6. Open the options page and confirm the blocklist can be edited, imported, and exported.

No login, credentials, paid account, or external service is required for testing the extension UI.
